# Scripture Trivia

Endless Bible story trivia. Every 5 correct answers is a new level, with word puzzles mixed in.

- `www/index.html` is the whole game.
- Pushing to `main` builds the Android APK automatically (see `.github/workflows/build-apk.yml`).
- Download the APK from the Releases page, under "Scripture Trivia (latest APK)".
